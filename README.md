# Northstar Banking Dashboard

A small banking-style dashboard built with Vue 3, the Composition API, TypeScript, Pinia, and Vue Router. It includes account summaries, searchable transactions, and a quick-transfer form with recipient, amount, and available-balance validation.

## Getting started

```sh
npm install
npm run dev
```

## Checks

```sh
npm run build
npm run test:unit
npm run test:e2e
```

The first end-to-end test run may require downloading Playwright's Chromium browser:

```sh
npx playwright install chromium
```
